# Intern Training

This repository contains the S3 Datacom 12-working-day intern training plan exercises. The individual practice app is an Airbnb-style hotel management app that will grow from static pages into a TypeScript API, database-backed React app, with authentication, tests, Docker, and CI.

## Repository layout

- `assignments/` — written work, requirements, daily logs, and design documents
- `solutions/` — coding and database exercise solutions
- `project/` — the individual hotel management practice app
