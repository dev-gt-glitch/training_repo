# Intern Training

This repository contains the S3 Datacom 12-working-day intern training plan exercises. The individual practice app is a task tracker that will grow from static pages into a TypeScript API, database-backed React app, with authentication, tests, Docker, and CI.

## Repository layout

- `assignments/` — written work, requirements, daily logs, and design documents
- `solutions/` — coding and database exercise solutions
- `project/` — the individual task tracker practice app

## Toolchain

Verified locally on Day 1:

- Node.js: `v26.0.0`
- Git: `2.50.1`
- Docker: `29.6.2`

The app's run instructions will be added as the project is built.
