# S3 DataCom

## Day 02 accessible signup form

The signup form is in [`assignments/Day-02/Form/signup.html`](assignments/Day-02/Form/signup.html).

### Accessibility

- Every input has a visible label.
- Native input types and constraints provide browser validation messages.
- The form can be completed using the keyboard alone.
- Visible focus styles are provided for inputs and the submit button.
