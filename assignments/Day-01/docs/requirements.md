| Story | ID | Role | Epic | Acceptance criteria | Priority |
| --- | --- | --- | --- | --- | --- |
| As an admin, I want to add a hotel with its name, location and address, so that guests can find and book it\. | A1 | Admin | Hotel setup | Name, location and address are required\. A saved hotel appears in guest search results\. | Must |
| As an admin, I want to add, edit and remove amenities for a hotel, so that guests know what facilities it offers\. | A2 | Admin | Hotel setup | Amenities \(e\.g\. WiFi, pool, parking\) attach to the hotel, not to rooms\. Changes show on the hotel page immediately\. | Must |
| As an admin, I want to add rooms to a hotel with room type, AC or Non\-AC, price per night and capacity, so that guests can choose the room that fits them\. | A3 | Admin | Room management | Room type \(Standard, Deluxe, Suite\), AC/Non\-AC, price and max guests are required\. Room is linked to exactly one hotel\. | Must |
| As an admin, I want to edit a room's details, so that listings stay accurate\. | A4 | Admin | Room management | All room fields are editable\. Price changes apply to new bookings only, not existing reservations\. | Must |
| As an admin, I want to delete a room, so that rooms no longer offered can't be booked\. | A5 | Admin | Room management | System asks for confirmation\. A room with upcoming reservations can't be deleted until they're resolved\. | Must |
| As a guest, I want to search hotels for my check\-in and check\-out dates, so that I only see hotels I can actually book\. | G1 | Guest | Search | Check\-out must be after check\-in and dates can't be in the past\. Only hotels with at least one room free for the full range are shown\. | Must |
| As a guest, I want to filter hotels by price, so that I can stay within my budget\. | G2 | Guest | Search | Filter by min and max price per night\. Results update without losing the selected dates\. | Must |
| As a guest, I want to select a hotel and see its amenities and available rooms, so that I can decide where to stay\. | G3 | Guest | Booking | Hotel page shows address, location, amenities, and rooms available for the chosen dates with type, AC/Non\-AC and price\. | Must |
| As a guest, I want to choose a room and add the guests staying with me, so that my reservation is complete\. | G4 | Guest | Booking | Number of guests can't exceed the room's capacity\. Total price is shown before confirming\. Confirmed booking blocks the room for those dates\. | Must |
| As a guest, I want to edit my reservation's dates, room or guests, so that I can adjust my plans\. | G5 | Guest | Manage booking | Availability and capacity are rechecked\. Updated total price is shown before saving\. | Must |
| As a guest, I want to cancel my reservation, so that I'm not charged for a stay I won't take\. | G6 | Guest | Manage booking | System asks for confirmation\. Cancelled room becomes available again for those dates\. | Must |
